# Инструкции для агентов

## Проект

«Банщик» — локальное русскоязычное веб-приложение с AI-консультантом банного комплекса.

- Сервер: Node.js, Express, OpenAI Responses API (`server.js`).
- Интерфейс: статические HTML, CSS и JavaScript в `public/`.
- Данные: SQLite через `sql.js`, файл `data/banshchik.sqlite`.
- Конфигурация: `.env`; образец переменных находится в `.env.example`.

## Запуск и зависимости

- Устанавливайте зависимости командой `npm install`.
- Запускайте приложение командой `npm start` и открывайте `http://127.0.0.1:3000`.
- Node.js 20 или новее.
- При запуске сервер проверяет заданную модель OpenAI. Если ключ или модель недоступны, сервер завершает запуск с сообщением об ошибке.

## Безопасность и данные

- Не читайте, не печатайте и не добавляйте секреты из `.env` в исходники, журналы, коммиты или ответы пользователю. Не включайте `.env` в Git.
- Сохраняйте привязку клиентских запросов к пользователю на сервере. Все административные маршруты должны проверять роль администратора через middleware.
- Клиентам запрещён доступ к административным API, данным других пользователей, истории диалогов и сохранённым фактам.
- Пароли храните только в виде стойких хешей; не добавляйте пароль администратора в публичный интерфейс.
- Сохраняйте данные между перезапусками в SQLite-файле `data/banshchik.sqlite`.
- Не передавайте параметр `temperature` в запросах OpenAI.

## Изменения

- Сохраняйте тексты интерфейса на русском языке.
- Не меняйте схему БД несовместимым образом без миграции существующей базы.
- Обновляйте `README.md` и `.env.example`, если меняются команды запуска или конфигурация.
