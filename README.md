# «Банщик» — локальный AI-консультант

Локальное веб-приложение для консультаций гостей банного комплекса. Node.js + Express, SQLite (файл `data/banshchik.sqlite`) и OpenAI Responses API. Регистрация открыта для клиентов; административный раздел защищён ролью на сервере.

## Запуск

1. Установите Node.js 20 или новее.
2. В `.env` укажите действительный `OPENAI_API_KEY`. Для модели по умолчанию используется `gpt-6-luna`; при необходимости можно задать `OPENAI_MODEL`. Не передавайте параметр `temperature`.
3. Установите зависимости: `npm install`.
4. Запустите приложение: `npm start`.
5. Откройте <http://127.0.0.1:3000>.

При старте приложение проверяет ключ и выбранную модель через OpenAI API; при ошибке завершает запуск и печатает понятное сообщение. Порт настраивается параметром `PORT` в `.env`.

## Учётные записи

- Клиент: регистрация по email и паролю от 8 символов.
- Администратор: логин `admin`, пароль `333` (предустановлен при первом создании БД).

## Данные

SQL-база хранится в `data/banshchik.sqlite`, поэтому переписывается между запусками. Диалоги и сообщения сохраняются полностью; в контекст модели передаётся вся переписка активного диалога. Полезные предпочтения извлекаются AI и сохраняются как приватные факты. Клиенты не имеют API-доступа к этим фактам, чужим профилям, административным разделам и истории диалогов. Администратор может искать клиентов, вести память/посещения, просматривать переписку и редактировать сведения о комплексе.

Ключ OpenAI хранится только в `.env`, который исключён из Git. `.env.example` содержит шаблон конфигурации.

В административной панели есть вкладка «OpenAI»: она показывает настроенную модель и результат проверки подключения, а кнопка «Проверить сейчас» повторно проверяет доступность модели. Значение ключа не показывается. В разделе «О комплексе» доступны четыре исходно заполненных описания объёмом более 100 слов каждое; их можно адаптировать к фактическим услугам и правилам организации.
